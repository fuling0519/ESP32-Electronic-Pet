# 小鳥花園互動展示

開啟 `index.html` 即可試玩；本頁不需要安裝套件。保留核准的粉彩像素風格，背景與 canvas 小鳥分開繪製。

提供待機、餵食啄食、清潔髒污減少、陪玩跳躍、日夜切換、重新試玩及鍵盤按鈕操作。照顧動作一次結算，數值上限 100；減少動態效果設定下停用持續動作。

這是獨立的 UI 展示，尚未接入既有 Flutter Web、BLE、帳號、API 或資料庫。展示資料不保存、不計算衰減／成長／死亡，不送出装置命令。裝置連線按鈕只開啟說明。

依 2026-10-01 GitHub Web 計畫及 project-plan §10：本頁不是 W1／W2／W5 驗收完成。真實操作依賴 W1、W3、BLE-S3；Web 正式首版命令為餵食、清潔、治療，陪玩目前僅為使用者要求的展示互動。進度宣告維持在主台帳。

下一步將動畫元件接入 Flutter Web 資料層，再以裝置快照驅動畫面。API、BLE 與 UI domain 應透過 mapper 分離。

背景由內建圖像工具根據已核准圖片移除中央小鳥。提示詞：只移除中央鳥、重建後方欄杆與灌木，保留空棲架、原有構圖、粉彩像素色盤、花朵、鳥屋；夜景保留月亮與星星。背景在 `assets/garden-day.png`、`assets/garden-night.png`。小鳥是程式繪製的像素圖，可替換為團隊正式美術。
