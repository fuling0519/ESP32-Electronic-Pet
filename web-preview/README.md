# 小鳥／小飛龍花園互動展示

入口為 `index.html`，首頁定位為**裝置陪伴頁**：預設裝置模式，只顯示連線與 ESP32 回報的資料，照顧、遊戲在裝置模式隱藏；直接點角色的摸摸／戳戳兩種模式都能用，只播反應、不改數值。上方右側的切換鍵在裝置模式顯示「進入展示模式」、展示模式顯示「回到裝置」。進入展示模式後才出現照顧、觸碰按鈕，以及頁面底部的「展示工具」。展示工具分兩區，都用可直接點的按鈕：

- **外觀預覽**（只換畫面，不改存檔）：種類（依存檔／小鳥／小飛龍）、階段（依存檔／幼年／成年）、動作（跟隨寵物、待機、移動、吃飯、開心、驚嚇、傷心、生病、睡覺、死亡；小鳥的待機已含走動，所以小鳥不能選「移動」）。
- **模擬寵物**（會改變展示存檔）：狀態（清醒／睡覺／生病／死亡，生病才會出現治療、死亡會走告別與紀念冊流程）、觸碰（摸摸／戳戳按鈕；也可直接點角色：按住約 0.7 秒是摸摸，輕點是戳戳，同韌體銅箔；只有動畫回饋，不改心情）、快轉成長（蛋 → 幼年 → 成年，含成長轉場）、送別、重設展示寵物（先確認；覆蓋成預設成年小鳥 Tamama，不留紀念冊）。

展示模式的「陪玩」可選「丟玩具（試玩）」：在花園裡按住畫面下方的球往花園甩出，寵物會追過去接住或撿回來，一場 5 球後固定心情 +6、EXP +10；花園上方的「結束陪玩」或 Esc 中途結束不結算，鍵盤可按 Enter 丟球。裝置模式連上支援網頁陪玩的電子雞（韌體宣告 `web_game`）後，電子雞在主畫面閒置時會出現「陪玩」按鈕，直接和真正的寵物丟玩具：由電子雞開局與結算，網頁只回報成績並顯示電子雞算出的增量；電子雞上同時顯示「網頁陪玩中」，長按可結束。展示模式另可選「花園合唱（試玩）」：寵物先唱一段，再點前排四朵花（或按 1～4）唱回去，共 3 首，依答對首數給獎勵；目前電子雞還不支援，裝置模式不能玩。猜拳與記憶音符暫時保留（只在展示模式）。

花園左上角的圓形狀態按鈕會彈出寵物狀態卡片（再按一次或點旁邊空白處收合），裝置與展示模式都能用；卡片底部有「📖 紀念冊」。操作訊息以字幕顯示在花園底部，約 4 秒後淡出。已存的資料來源偏好照舊沿用。

在外觀預覽的「種類」可選小飛龍；此選項不改寫個體種類，領養新蛋仍各 50% 抽選並保存。

成年小飛龍已接入獨立彩色像素素材：待機、傷心、生病、開心、蜷縮睡眠、死亡靜態，以及飛行靜態造型。可先開啟 [全部狀態總覽](wyvern-states-preview.html) 並排比較及切換日夜背景；總覽不讀寫寵物存檔。`index.html?preview=wyvern` 會預選小飛龍，可用外觀預覽的「動作」切換各種素材，不改養成數值。成年資產與邊界見 [成年素材說明](assets/pets/wyvern/adult/README.md)。先前幼年 v1 及大幅振翅待機稿未採用；[舊稿檢視頁](wyvern-art-preview.html) 與 [設計記錄](assets/pets/wyvern/ART-DIRECTION.md) 保留歷史資料。

[待機獨立預覽](wyvern-idle-preview.html) 及 [傷心／生病／開心六格表情預覽](wyvern-emotions-preview.html) 保留。待機與表情已由使用者確認；本輪整合的比例、自然度及瀏覽器畫面仍待確認。飛行六格與吃飯四格已接入：吃飯為低頭咬與抬頭嚼交替三口、食盆逐口減少，碗空後微笑。被戳專用角色圖尚未完成，暫以小幅彈動和驚嘆號過渡，死亡靈魂已改由 `death-view.js` 從各物種待機圖程式生成，可在 [長眠流程預覽](death-preview.html) 檢查。幼年保留既有呈現。

採用新的像素農場午後／夜晚背景，保留寵物美術。展示模式提供照顧、健康／睡眠展示、成長、死亡告別、本地墓園與領養，資料保存在此瀏覽器。裝置模式接入 BLE v1 Adapter：查詢資訊／狀態，並在韌體支援時送出 Web 陪玩的遊戲命令；照顧命令仍停用。

畫面透過 DataManager 讀取資料與發起操作。舊展示存檔及 BLE 快取的相容方式、介面與離線測試指令見 [資料層交接](DATA-LAYER.md)。完整實作／測試／待驗收狀態只看 [主企劃第 10 節](../docs/project-plan.md#progress)。

file URL 只供大致試玩：瀏覽器禁止讀取圖片像素，死亡光環、光點、送別照片與觸碰範圍會改用預設值，頁面頂端顯示提示，請改用根目錄的 `開啟網頁.cmd`；實際 Web Bluetooth 需支援的瀏覽器及 HTTPS／localhost。不同來源不共用本地存檔；清除瀏覽器資料會移除本地紀錄。重開頁面的 BLE 快取標為舊資料，不自動連線、不補算裝置養成。

本頁尚未接入 Flutter Web、帳號、API 或雲端資料庫；本地墓園只含實際觀察保存的資料，缺少存檔世代時不代表完整裝置歷史。Web 本地邊界依主企劃及 Web 計畫；本輪已同步 10/9 文件。
