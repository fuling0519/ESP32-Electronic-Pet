# 小鳥／小飛龍花園互動展示

入口為 `index.html`，首頁定位為**裝置陪伴頁**：預設裝置模式，只顯示連線與 ESP32 回報的資料，照顧、遊戲、觸碰在裝置模式隱藏。上方右側的切換鍵在裝置模式顯示「進入展示模式」、展示模式顯示「回到裝置」。進入展示模式後才出現照顧、觸碰，以及頁面底部的「展示工具」區塊（背景／種類／素材階段／生命階段／展示狀態、小龍／小鳥素材、傷心預覽、送別、重新試玩）。已存的資料來源偏好照舊沿用。

在展示工具的「種類」可選小飛龍；此選項不改寫個體種類，領養新蛋仍各 50% 抽選並保存。

成年小飛龍已接入獨立彩色像素素材：待機、傷心、生病、開心、蜷縮睡眠、死亡靜態，以及飛行靜態造型。可先開啟 [全部狀態總覽](wyvern-states-preview.html) 並排比較及切換日夜背景；總覽不讀寫寵物存檔。`index.html?preview=wyvern` 的成年小龍另有「小龍素材」外觀選單，不改養成數值。成年資產與邊界見 [成年素材說明](assets/pets/wyvern/adult/README.md)。先前幼年 v1 及大幅振翅待機稿未採用；[舊稿檢視頁](wyvern-art-preview.html) 與 [設計記錄](assets/pets/wyvern/ART-DIRECTION.md) 保留歷史資料。

[待機獨立預覽](wyvern-idle-preview.html) 及 [傷心／生病／開心六格表情預覽](wyvern-emotions-preview.html) 保留。待機與表情已由使用者確認；本輪整合的比例、自然度及瀏覽器畫面仍待確認。飛行六格與吃飯四格已接入：吃飯為低頭咬與抬頭嚼交替三口、食盆逐口減少，碗空後微笑。被戳專用角色圖尚未完成，暫以小幅彈動和驚嘆號過渡，共用靈魂仍沿用舊版。幼年保留既有呈現。

採用新的像素農場午後／夜晚背景，保留寵物美術。展示模式提供照顧、健康／睡眠展示、成長、死亡告別、本地墓園與領養，資料保存在此瀏覽器。裝置模式接入 BLE v1 唯讀 Adapter，僅查詢資訊／狀態；照顧命令仍停用。

畫面透過 DataManager 讀取資料與發起操作。舊展示存檔及 BLE 快取的相容方式、介面與離線測試指令見 [資料層交接](DATA-LAYER.md)。完整實作／測試／待驗收狀態只看 [主企劃第 10 節](../docs/project-plan.md#progress)。

file URL 可供美術試玩；實際 Web Bluetooth 需支援的瀏覽器及 HTTPS／localhost。不同來源不共用本地存檔；清除瀏覽器資料會移除本地紀錄。重開頁面的 BLE 快取標為舊資料，不自動連線、不補算裝置養成。

本頁尚未接入 Flutter Web、帳號、API 或雲端資料庫；本地墓園只含實際觀察保存的資料，缺少存檔世代時不代表完整裝置歷史。Web 本地邊界依主企劃及 Web 計畫；本輪已同步 10/9 文件。
