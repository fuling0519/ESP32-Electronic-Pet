# 小鳥花園互動展示

開啟 `index.html` 即可試玩；本頁不需要安裝套件。保留核准的粉彩像素風格，背景與 canvas 小鳥分開繪製。

提供待機、餵食啄食、清潔髒污減少、陪玩跳躍、日夜切換、重新試玩及鍵盤按鈕操作。照顧動作一次結算，數值上限 100；減少動態效果設定下停用持續動作。

這是獨立的純前端展示與 BLE v1 唯讀頁面，尚未接入既有 Flutter Web、帳號、API 或伺服器資料庫。展示資料及偏好保存於 LocalStorage，含前端照顧／生命階段／死亡與觀察式本地墓園；裝置模式只讀取、驗證並快取真實快照，不送出照顧命令。裝置連線說明提供搜尋、連線與斷線操作，限制見下方本地模式與 BLE 增量。

依 2026-10-01 GitHub Web 計畫及 project-plan §10：本頁不是 W1／W2／W5 驗收完成。真實操作依賴 W1、W3、BLE-S3；Web 正式首版命令為餵食、清潔、治療，陪玩目前僅為使用者要求的展示互動。進度宣告維持在主台帳。

展示與裝置資料層已分離；接著驗收本地保存、行動版及真實裝置唯讀相容性。帳號與 API 屬後續雲端方向；若啟動，API、BLE 與 UI domain 仍需透過 mapper 分離。

背景由內建圖像工具根據已核准圖片移除中央小鳥。提示詞：只移除中央鳥、重建後方欄杆與灌木，保留空棲架、原有構圖、粉彩像素色盤、花朵、鳥屋；夜景保留月亮與星星。背景在 `assets/garden-day.png`、`assets/garden-night.png`。小鳥是程式繪製的像素圖，可替換為團隊正式美術。
# 2026-10-02 本地模式與 BLE 唯讀增量

頁面支援展示與裝置模式，展示資料及偏好分別保存於 LocalStorage。裝置模式的「裝置連線說明」提供搜尋、等待、取消、錯誤與中止／斷線操作；僅送 `get_device_info`、`get_status`，不送照顧命令。此增量尚未實機驗收。

BLE 需使用支援 Web Bluetooth 的瀏覽器，從 HTTPS 或 localhost 開啟；file URL 僅供美術試玩。快照經完整驗證後保存於獨立 `aviary.device-snapshot`，重開顯示接收時間與舊資料標記，不自動連線、不補算數值。清除網站資料會移除本地紀錄；不同來源（file、localhost、部署網域）不共用存檔。

目前只快取最後一台装置的快照；不是多裝置管理或擁有權認領。損毀／不相容資料保留並提示，不靜默覆寫。規範與唯一進度台帳請見 `docs/project-plan.md`。
