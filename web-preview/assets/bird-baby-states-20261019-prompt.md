# Baby Web expressions

Built-in imagegen edit of bird-sage-v4.png, 2026-10-19. Source exec-b11e778e-40fc-41c8-95cd-e35f91898db9.png. Six horizontal cells: normal open, normal blink, sad open, sad closed, sleeping, eating. Preserve green baby bird identity, cream belly, peach cheeks, empty wings and transparent background. Equal cell sizes, same baseline, coarse pixel art; no labels, props, Z or sadness lines. This generated 2172x724 sheet is not a native 64x88 OLED asset. Web samples equal sixths; actual crop consistency needs browser review.

Official shared masks are exported unchanged from BirdSprite.h (bowl), PotionSprite.h, DirtySprite.h and CleaningSprite.h at repository commit 14d7acc. Native sizes and byte counts are tested separately.
