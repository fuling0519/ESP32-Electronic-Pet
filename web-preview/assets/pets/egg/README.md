# 蛋 Web 素材（2026-10-24）

後續製作沿用 [Web 寵物精靈圖製作規則](../../../../docs/web-sprite-workflow.md)，當次使用者指示優先。

## 造型

三種花紋共用同一個蛋形、描邊、光源與像素顆粒。使用者 2026-10-24 決定三顆都用：每顆新蛋依 `petId` 固定挑一種，只影響 Web 外觀，物種仍由既有規則隨機決定，跟花紋無關，所以三顆要看起來同等級，不能有一顆像稀有蛋。

| 順序 | 花紋 | 蛋殼 | 處理 |
|---|---|---|---|
| 0 | 斑點蛋：大小不一的咖啡、焦糖色斑點 | 奶油色 | GPT 原圖，不改色 |
| 1 | 點點蛋：大小不一的散落點點 | 薄荷色（色相 160） | 點點位置和大小照原圖；粉點改成 `#f6afda`，原本的綠點改成 `#9ce0ea` |
| 2 | 波浪紋蛋：中間一條波浪帶，上緣有細亮線 | 淡黃色（色相 50） | 波浪改成天藍 `#78b9f0` |

改色都保留 GPT 的明暗、描邊、高光和邊緣混色；暗面的點點和波浪也會跟著變暗。

### 裂痕與破殼的做法

GPT 分別在三顆蛋上畫裂痕，會重畫整顆蛋，花紋會跑掉；所以只請它畫一顆素色蛋，其餘由程式套用：
- **大裂痕**：素色蛋「大裂痕」減「完整」的差異，等比例對到每顆蛋的範圍上。深色線條用裂痕褐色，淺色邊改成把底下的殼色調亮，配合各蛋殼色。
- **小裂痕**：取大裂痕中間 30% 寬度裡最大的一段，讓裂痕從同一處長大，不會跳位。GPT 自己畫的小裂痕形狀不同，所以不採用。
- **上蓋／下半殼**：沿主裂痕線（跳過分岔）把正式的蛋切開，殼外花紋與完整蛋一致。兩邊斷口都只補上 12px 描邊與淺色殼厚，不畫內壁。
- **破殼只微微分開**：第一版下半殼畫了開口與內壁，使用者覺得缺口怪，張太開又會顯得裡面是空的（2026-10-24）。所以轉場時上蓋只沿裂縫稍微抬起（預計約蛋高的 4%），用裂縫透光帶過，不露出蛋殼內部。GPT 原圖的下半殼與上蓋格因此不使用。

## 未採用

- PixelLab 試做（4 次產圖）：附小鳥當風格參考時，蛋長出了五官和尾巴；拿掉參考後，斑點又排成臉，手改後使用者覺得不好看。原檔只留在本機暫存，不入庫。
- 點點蛋改色過程中也試過：多色糖果點點（有反光／無反光）、所有點點放大成同尺寸再錯開排列。使用者覺得怪，最後回到原圖的點點配置。
- `egg-watercolor-source-v1-rejected.png`（只留在本機，不入庫）：用 `egg-watercolor-v1-prompt.md` 產的第三顆蛋。色塊邊緣模糊、沒有明暗，跟另外兩顆畫風不一致，用程式減色也修不好。`egg-pastel-patch-v2-prompt.md` 是修正後的提示詞，但使用者改為保留波浪紋蛋、只換顏色，所以沒有送出。



## Web 接入（2026-10-24）

- `egg-view.js`：依 `petId` 選花紋（`PetEggView.design`），孵化中／小裂痕／大裂痕使用上表圖格；蛋底部在畫布 (190,200)、高 84px。晃動與呼吸是整張圖的輕微旋轉與壓扁，大裂痕的透光由程式沿 `crackLine` 畫出。
- `growth-view.js`：孵化轉場 4.2 秒，上蓋抬起、縫隙透光、閃白與小碎殼由程式繪製；寶寶出現後的閃光沿用清潔完成的 `sparkle` 圖集。`egg-hatch-data-v1.js` 是給 file:// 頁面讀取的同內容資料檔。
- 預覽：`growth-preview.html` 可選三種花紋重播。驗證與未驗收範圍見專案計畫第 10 節「2026-10-24 Web 彩色蛋、裂痕與新出生轉場」。
