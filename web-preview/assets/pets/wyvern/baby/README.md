# 幼年小飛龍 Web 素材（2026-10-23）

後續製作沿用 [Web 寵物精靈圖製作規則](../../../../../docs/web-sprite-workflow.md)，當次使用者指示優先。

`idle-preview-v1.png` 是 2026-10-20 的舊幼年稿，**方向未採用**，不作為參考。

## 造型

以成年 `../adult/idle-preview-v1.png` 推導，經 v1→v2 修正：頭約佔身高 65%、豆子形短身體、角只剩兩顆奶油色小鼓包、無額前突起、耳朵與翅膀更小（飛不起來，移動用走的）、腹部只有兩條淡分節、五官略低。小豆眼、`w` 嘴、腮紅不變。使用者看過 v2 後決定不重畫（2026-10-23）；希望顏色更淡，採後製把薰衣草紫皮膚調淡 25%（外框、眼睛、腮紅、奶油色不動）。

**姿勢與成年不同**（使用者 2026-10-23 確認）：幼龍睡覺是**坐著打瞌睡**、死亡是**正面整隻攤平趴著**。趴睡與側躺試了四次（C、睡覺 v2、死亡 v2、v3），每次都在耳朵、角、五官或身體長度上偏向成龍；正面姿勢則一次到位。

## Web 呈現（`wyvern-adult-view.js`，同時負責成年與幼年）

- 大小：待機 92px 高，約成年的 73%。每張生成圖畫的幼龍大小不同，繪製時換算：B＝A×231/219、C＝B×220/295（頭寬）、睡覺／死亡＝A×107/193.8（兩眼間距）。
- 狀態：待機（四格翅膀收放＋搖尾巴）、傷心、生病、開心（摸頭固定瞇眼笑格）、驚嚇（戳戳）、吃飯（咬／嚼三輪後以開心瞇眼格當微笑，食盆寬 48、底 196）、睡覺（坐著打瞌睡靜態、以錨點水平翻轉，Zzz 在 (208,86)）、死亡（正面攤平，沿用五秒淡出與共用靈魂）。優先順序與成年相同。
- 走路：走路第 3 格借用 C 的換腳格。健康清醒待機時，地面停留 24 秒後走 9840 ms（右 60px → 轉身 → 左 120px → 轉身 → 回中央），往左鏡像，轉身時停在站立格；照顧、互動、傷心、生病、睡眠與對話框會中斷，減少動態時停在待機。節奏是暫定值。
- 觸碰範圍 rx 62／ry 56，愛心與驚嘆號的頭部位置另設。主頁、成長轉場、紀念冊、清潔場景與 `wyvern-states-preview.html`（「切換幼年」）共用同一繪製入口；圖片未載入時退回原遮罩。
