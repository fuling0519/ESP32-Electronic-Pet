# 幼龍睡覺＋死亡 v3 提示詞（2026-10-23 草稿）

使用者回饋：睡覺 v2、死亡 v2 比較像成龍。並排比較（同一遊戲比例）後的原因：
- **耳朵**：待機是小小圓圓、長在頭兩側中段；v2 變成又大又尖、長在頭頂兩角，跟成龍一樣。
- **額前突起**：待機幾乎沒有；v2（尤其死亡）冒出明顯的紫色尖突，是成龍特徵。
- **角**：待機是圓圓的小鼓包；v2 變高、偏尖錐。
- **五官**：待機眼睛在頭的下半、間距寬；v2 眼睛往上移、間距變窄。
- **身體長度**：死亡照成龍側躺，身體和尾巴拉長到約頭寬的 2.3 倍；幼龍應該短短一團。
- **參考鏈漂移**：睡覺 v2 以 C 的睡姿為參考，死亡 v2 又以睡覺 v2 為參考，一路離開 A 的造型；成龍姿勢圖也把成龍特徵帶進來。

本版修正：**只附 A，不附任何成龍圖或後來的睡姿圖**，姿勢只用文字描述；兩格畫在同一張，彼此一致。
