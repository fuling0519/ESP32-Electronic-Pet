# 成年龍六格表情圖集 v1

請以附上的「已確認成年小飛龍正面圖」為唯一造型與畫風依據，製作一張高品質彩色像素風的成年龍表情精靈圖集。

【角色與畫風】
所有畫格必須是同一隻成年龍。
保留參考圖的頭身比例、紫色圓臉、小豆眼、小嘴、腮紅、奶油色角、額前突起、粉紫耳內、分節腹部、短小四肢、小翅膀與捲尾。
延續參考圖柔和精緻的彩色像素風，維持相同的像素密度、描邊、配色與左上方光源。
保留淡紫亮面、冷紫陰影，以及翅骨和翅膜的材質層次。
表情清楚自然，縮小觀看仍能辨識。不要放大眼睛、改變臉型或增加黃色口鼻面罩。

【圖集配置】
兩欄、三列，共六個等大的正方形畫格。
每列呈現同一種情緒，左格睜眼，右格閉眼。
所有角色完整入鏡，中心位置、基本大小與腳底基準一致，四周保留透明空間。
同一列的兩格必須保持相同姿態、頭部位置與翅膀形狀，主要差異是眼睛開合；避免眨眼時身體突然跳動或變形。

【第一列：傷心】
左格：傷心睜眼。
眉毛內側微微上揚，小豆眼流露委屈，小嘴輕輕下垂。
身體略顯低落，翅膀比平常低垂、稍微收攏，翼尖放鬆地朝下。
保持可愛、溫和的失落感，不嚎哭，不畫眼淚或漂浮符號。
右格：傷心閉眼。
延續左格的姿勢、眉毛與嘴形，只將眼睛輕輕閉上。
仍然能看出委屈，不要變成開心笑眼或安穩睡眠。

【第二列：生病】
左格：生病睜眼。
眼皮低垂、雙眼半睜，眉眼疲倦，小嘴微微放鬆，呈現身體不舒服、提不起精神的感覺。
頭部可略微低下，雙手放鬆。
翅膀鬆垂並更貼近身體，翅膜自然放鬆，沒有精神振翅。
右格：生病閉眼。
保持左格的疲倦姿勢，眼睛無力地閉上。
眉眼仍帶著不適，與傷心的委屈、睡眠的放鬆明確區分。
維持原本紫色皮膚，不改成綠色或灰白色。
不畫體溫計、藥瓶、繃帶、汗滴或其他醫療符號。

【第三列：開心】
左格：開心睜眼。
保留原本小豆眼的大小，以柔和的眉眼、略微提起的臉頰與小小微笑表現愉快。
身體自然挺起，翅膀在身側輕輕舒展，仍維持小巧、放鬆的幅度。
右格：開心閉眼。
保持左格姿勢，雙眼閉成向上彎的滿足笑眼，嘴巴維持小小微笑。
像被輕摸後舒服又開心的樣子，不大笑、不張大嘴、不露牙。
翅膀不抬到耳旁或頭頂，也不做出準備起飛的姿勢。
不畫愛心、星光或人的手。

【一致性與輸出】
不同情緒可以有自然的姿態差異，但角色比例、肢體結構、受光與細節設計必須一致。
傷心與生病的翅膀都呈現沒精神的狀態，兩者分別強調委屈和疲倦。
不要靠誇張扭曲五官或大幅改變翅膀姿勢來區分情緒。
輸出真正透明背景的 RGBA PNG。
各格不得互相重疊，不裁切角、翅膀、腳或尾巴。
不包含背景、地面、投影、光暈、格線、文字、編號或特效。
