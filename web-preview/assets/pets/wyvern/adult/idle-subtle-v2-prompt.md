# 成年龍微幅振翅待機 v2

請以附上的「已確認成年小飛龍正面圖」為唯一角色造型與畫風依據，製作一張高品質彩色像素風的「小幅振翅待機」精靈圖集。

【角色與美術】
這是同一隻已確認的成年龍，請保留原本的頭身比例、紫色圓臉、小豆眼、小嘴、腮紅、奶油色角、額前突起、耳朵、分節腹部、短小四肢、翅膀與捲尾。
延續參考圖柔和、精緻的彩色像素表現，保留清楚的明暗層次、淡紫亮面、冷紫陰影，以及翅骨與翅膜的材質區別。
整體適合溫暖、色彩豐富的像素花園場景。
不要改變造型、放大眼睛、增加黃色口鼻面罩，或改成粗糙的單色填色圖。

【待機動作的氣質】
小龍雙腳著地，悠閒地站著，翅膀在身側輕輕活動。
動作輕盈、有生命感，但非常放鬆，沒有準備起飛或用力拍翼的感覺。
翅膀始終留在參考圖原本位置附近的小範圍內。
翼根穩定，以外側翼尖與翅膜的輕微展開、回彈、收攏形成動作。
翅膀主要維持向側下方伸展，不抬到耳旁、頭後或頭頂。
不要將整片翅膀大幅上下旋轉，也不要突然展寬成飛行姿勢。

【四格連續動作】
採 2 欄 × 2 列排列，依左上、右上、左下、右下播放。
第一格 A：以參考圖的自然展翼姿勢作為循環起點，表情輕鬆。
第二格 B：翼尖輕輕向外舒展，翅膜略微張開。變化集中在翅膀外側，幅度細微，仍緊鄰原本輪廓。
第三格 C：翅膀柔和地回到接近自然位置，翅膜隨動作輕微回彈。呈現舒展後的連續過渡，不是另一個大幅度翼姿。
第四格 D：翼尖略向內收，翅膜稍微放鬆，準備回到第一格。D 接回 A 時應自然連貫，沒有突然跳動。
四格應像同一個小動作的連續瞬間，而不是四種不同姿勢。
請讓差異細緻但在連續播放時可辨認，不要把四格畫成完全相同的複製圖。

【畫格一致性】
四格使用完全相同的角色大小、視角、配色、光源與像素密度。
頭部、身體、手腳與尾巴保持穩定，雙腳固定在相同基準位置。
本張專注於翅膀動作，雙眼保持睜開，保留原本的小小微笑。
不要靠移動、縮放或拉伸整隻龍來製造動畫。

【構圖與輸出】
四個等大的正方形畫格，角色中心與腳底對齊。
完整呈現角、翅膀、腳與尾巴，各格四周預留足夠透明空間，互不重疊。
輸出真正透明背景的 RGBA PNG。
不包含背景、地面、投影、光暈、格線、文字、編號或特效。
