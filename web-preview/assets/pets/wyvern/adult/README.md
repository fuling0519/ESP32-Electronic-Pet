## Web 整合現況

- `wyvern-adult-view.js` 已接入成年待機、傷心、生病、開心、睡眠及死亡；`wyvern-view.js` 優先使用彩色素材，幼年與圖片未載入時保留原有遮罩呈現。
- `sleep-00.png`／`sleep-01.png` 與 `sleep-preview-v1.apng` 從先前睡眠預覽目錄原樣複製；各格 887×640、1100／900 ms，保持同一定位與縮放。
- `dead-still-v1.png` 為本輪生成的 1684×934 RGBA 死亡靜態圖，閉眼、嘴角下垂、側躺。實際死亡沿用原本五秒淡出、共用靈魂和墓碑流程；不為小龍加 XX 眼。
- 成年成長轉場、送別照片與紀念冊的無照片替代圖也使用新素材。紀念冊長眠採死亡圖；遠行採待機圖。
- `web-preview/wyvern-states-preview.html` 以相同繪圖程式並排播放七種外觀、切換日夜背景，不讀寫存檔。正式展示頁的成年小龍提供純外觀選單，僅在展示模式開放，切回其他物種／階段／裝置模式或終止狀態時重設。
- 飛行目前只接入已確認的靜態造型供選單／總覽查看，沒有宣稱完成飛行動畫。吃飯先使用待機搭配獨立食碗；被摸使用開心圖，被戳先用小幅彈動與驚嘆號；共用靈魂待重製。
- 自動驗證：提交前執行 `node --test web-preview/*tests.cjs`，45 項檢查通過，涵蓋實際 PNG 裁切邊界、比例、共同定位、非等速節奏、減少動態、狀態優先序、預覽不改數值、正式 UI 的圖源切換，以及照顧／死亡／領養／成長回歸。自動瀏覽器未能連上本機 HTTP 預覽，file URL 亦不受工具支援；整合畫面、美術比例及動畫自然度待使用者本機確認，不推定硬體驗收。

圖集製作只裁切、整數平移、補透明留白及無損封裝，未縮放或重畫角色像素。已驗證六個獨立輪廓、PNG CRC、六個 APNG 畫格及正規化圖集／靜態預覽的無損像素往返。使用者已確認三組表情預覽；現已接入 Web，整合後的體型、姿態與連貫性仍待確認。機械檢查不代表美術驗收。

`tools/build_wyvern_idle_preview.py` 可重建圖集、動畫與 JSON。已驗證 PNG 區塊 CRC、四個 APNG 畫格及正規化圖集的無損像素往返。
