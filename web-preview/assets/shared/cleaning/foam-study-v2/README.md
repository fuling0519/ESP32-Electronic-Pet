## 素材

- [實際生成提示詞](foam-prompt-v2.txt)：使用內建imagegen，要求真正透明背景。
- [原始生成圖](foam-source-v2.png)：1536×1024 RGBA，3欄2列，各512×512。
- [播放圖集](foam-sheet-v2.png)：RGBA像素與來源完全相同，未重畫、改色、去背或逐格縮放。原圖中全透明像素帶有RGB，部分工具看似光暈；[真Alpha淺底合成](source-on-cream.png)用來檢視實際合成。
- [描述資料](manifest.json)、[預覽覆載資料](foam-data.js)、[檔案驗證](validation.json)：固定錨點(256,280)，飽滿格可見寬458來源像素；各團名義顯示寬25～32 px，幼年配置沿角色比例調整。海綿仍一律60 px。

六格依序是少量、中量、飽滿、沖鬆、殘泡、破泡。較大的奶油白泡體、淡藍陰影與藍灰輪廓減少密集小圈；三個生長格及三個沖散格的Alpha總量依序增／減。完整消失由播放器隱藏提供，沒有另製空白畫格。各格保留生成的自然形狀差異，沒有聲稱泡體拓撲逐像素相同。

`foam-data.js`在v1的`animation-data.js`之後載入，只覆載foam描述；檔案路徑相對於播放器原有的`animation-v1/`基底。其餘五份素材沿用，當前預覽共六份圖集／26個有效畫格；v1原始28格及圖源留存。

## 動態

本輪沿用4.2秒流程，以便比較泡沫修正。先在胸腹放5團測試同一輪廓，包含不同大小與最高泡量；不把這個小樣配置當成最終三種輪廓。

- `foamSchedule`由同一海綿／蓮蓬頭路徑計算各團接觸，採1/240秒固定取樣並快取四種角色結果；暫停拖曳、不同播放幀率及重播使用相同事件。接觸區是胸腹上的近似幾何範圍，沒有宣稱逐像素水滴碰撞或流體模擬。
- 海綿持續接觸累計25ms，延遲100ms後出現少量泡，約250ms逐步長到該團最高泡量；海綿移開後泡留在身上，不畫拖痕。下方泡團隨擦洗路徑較晚出現。
- 水流主要沖洗區掃到泡團後累積接觸量，較下方需要稍多接觸，再局部沖鬆／殘泡／破泡，最後60ms僅收掉殘片。充分起泡的團使用沖鬆格；較少泡量的團直接減到殘泡，避免水一來反而增量。殘泡最多向下移1.5 px。
- 正常路徑全部泡團在3.4秒前消失；偏移海綿不會憑時間生泡，偏移水流也不會憑固定全域時鐘沖散。減少動態顯示同一配置的固定最高泡量。
