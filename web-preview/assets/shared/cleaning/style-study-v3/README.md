# 共用清潔・60 px 海綿樣稿 v3

2026-10-22：使用者要求改畫洗澡海綿，尺寸約 60 px，不隨幼年寵物縮小。這輪只新增一張靜態海綿，泡沫沿用 v2 的少／中／多樣稿。

- `sponge-source-v3.png`：內建 imagegen 生成，1402×1122 RGBA；參考 v2 肥皂的配色／描邊及成年小龍風格，重新畫成短胖、帶不規則孔洞與邊緣的奶油黃海綿。正面略傾斜，沒有角色、手或內建泡沫。實際提示見 [prompts.md](prompts.md)。
- `sponge-sample-v3.png`：以 alpha >=160 量測主輪廓後裁切留白，保留裁切區內全部 RGBA，沒有改色、重畫或拉伸。原圖、雜湊、裁切範圍與顯示設定見 [metadata.json](metadata.json)。
- 四種現有角色／階段的海綿一律 60 px 寬，約 43 px 高，以 384×256 遊戲畫布計算；幼年不縮小。配合增加的高度，海綿向胸腹下方定位，避免擋住臉。泡沫沿用原先階段比例，本輪沒有重畫或改變其尺寸規則。
- [v3 比較頁](../../../../cleaning-style-preview-v3.html) 使用現有角色播放器，海綿與泡沫使用共用試樣繪圖函式。`study-settings-v3.js` 記錄海綿圖源、60 px 預設寬與不隨幼年縮小的設定。
- [v2 肥皂頁](../../../../cleaning-style-preview-v2.html) 保留供比較；v1 也保留。v2 細長肥皂未獲採用，不當作已確認造型。
- `scene-contact-v3.png`：四種角色／階段的日夜場景；`quantity-scenes-v3.png`：成年鳥／龍與三種泡沫；`size-contact-v3.png`：海綿與泡沫原尺寸、4 倍細節。這些是共用繪圖函式合成圖，並非瀏覽器截圖。
- 已在本機瀏覽器檢查日夜顯示、預設 60 px 與四種角色／階段；`browser-preview-v3.png` 為白天、中量泡沫的實際畫面。已檢查真 Alpha、裁切 RGBA 無損、預覽引用與 JavaScript 語法。這些檢查不代替使用者對造型／比例的確認或完整動畫驗收。

重建：有 `@napi-rs/canvas` 的 Node.js 執行 `node tools/render_cleaning_style_study.cjs v3`。

狀態：已生成靜態海綿並整理至獨立預覽。孔洞與輪廓、擦拭視角、60 px 遮擋比例仍待使用者確認；尚未製作完整清潔動畫，也未接入正式清潔流程或修改韌體／養成規則。幼龍仍沿用原有遮罩版本，不代表幼龍美術已更新。

使用者後續提供兩端圓胖、中間收腰的海綿參考，指出 v3 橢圓不是預期輪廓；v3 不作為已採用造型，新版見 [v4](../style-study-v4/README.md)。
