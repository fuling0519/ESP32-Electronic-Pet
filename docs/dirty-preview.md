# 汙點快速預覽

接上 ESP32，關閉占用序列埠的監控視窗，雙擊專案根目錄的 `upload-dirty-preview.cmd` 即可編譯並上傳。
若同時接了多塊開發板，可使用 `pio run -e esp32dev_dirty_preview -t upload --upload-port COM埠號` 指定目標。

預覽直接使用成鳥，每 4 秒循環：100（無）→75（左上）→50（加右上）→25（加右下）。

- 左／右：切換清潔階段。
- 按一下：暫停／恢復自動切換。
- 上：播放吃飯動畫。
- 下：切換睡覺／清醒。

預覽不讀寫存檔、不推進需求衰減；測完重新上傳 `esp32dev` 即可恢復原本存檔。
這是畫面預覽，不是清潔互動玩法測試。

`assets/dirty/dirty.png` 為 38×48 圖集，每格 19×24，依左上、右上、左下編為第一、第二、第三張。
正式遊戲的幼鳥、成鳥主畫面（含吃飯）與睡眠畫面會依既有四段清潔度顯示汙點。
第二張在 (22,6)、第三張在 (90,2)、第一張在 (90,30)，保留左下給碗；睡眠時的 Zzz 顯示在 (78,17)，避開右上汙點。
更新 PNG 後執行 `tools/generate_dirty_sprite.ps1` 重新產生韌體點陣資料。
