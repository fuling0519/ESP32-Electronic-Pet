## 重跑

先完成一次 `pio run -e esp32dev` 取得 U8g2 依賴，再在專案根目錄使用有 `gcc`／`g++` 的 PowerShell 執行：

```powershell
./tools/test_rps.ps1
python tools/render_rps_preview.py
```

第二行需要 Pillow。`tools/generate_rps_icons.py` 可重新產生目前手勢及單獨素材預覽；未來換圖時維持 24×18 單色及 Display::drawGlyph 的 row-major／MSB-first／0 為亮點約定。

## 上板驗收

1. 使用正常 `esp32dev` 韌體及現有寵物存檔，確認幼鳥／成鳥健康清醒後進主選單「陪玩」。蛋請先等孵化，生病請先治療。
2. 短按開始；左右選招並確認兩端停住，短按出拳。倒數期間切換方向不得改變出拳；揭曉停留，短按前進。
3. 玩滿三回合，對照每回合勝負與最後比分；獲勝／平手／落敗分別 +15／+10／+5，心情上限 100。未到上限時應顯示完整增加量，接近上限顯示實際增加量，滿值顯示 +0。
4. 在選招、倒數、第一／第二回合揭曉時長按退出，確認無獎勵。在第三回合揭曉後退出，確認只保留一次獎勵；退出回主選單的陪玩項。
5. 在「再玩？」頁上下切換，預設返回。連續十場及反覆中途離開，確認回合／比分不殘留、長按放開不誤觸。
6. 手機 BLE 連線下遊玩，確認按鍵／音效正常，最後心情變動同步；手機斷線後仍能玩，重連讀取正確心情。
7. 結算後等待至少 12 秒再正常重開機，確認有效存檔保留心情。存檔沿用至少 2 秒延後及兩次保存間至少 10 秒限制；剛結算立刻拔電不保證保存。
8. 另外測試成長測試環境的比賽中長大，並用可控資料驗證中途生病／死亡；不得發未完成獎勵。切換測試環境前遵守各環境的存檔規則。
9. 回歸餵食、清潔、治療、一般／省電睡眠及正常重啟；量測遊戲與 BLE 並行 heap。將實機結果記回主企畫 A5-GAME，附韌體版本及未測項目。

儲存失敗、突然斷電及 BLE 長時間壓力仍需硬體驗收；一場遊戲的去重旗標只存於 RAM，重開機不恢復、重播或補發該場結果。
