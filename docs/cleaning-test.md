# 清潔動畫驗收

2026-10-03｜韌體 1.4.0 工作目錄｜最新實作及驗證結果統一見主企畫第 10 節「清潔動畫增量」。

## 重跑自動檢查

1. 用有 Pillow 的 Python 執行 `tools/generate_cleaning_sprite.py`。
2. 用有 gcc／g++ 的 PowerShell 執行 `tools/test_rps.ps1`，包含實際 U8g2 framebuffer 的 UI 測試及原有寵物／猜拳／心情回歸。
3. 用有 Pillow 的 Python 執行 `tools/render_cleaning_preview.py`，查看 `docs/cleaning-preview.png` 及幼鳥／成鳥 GIF。
4. 執行 `pio run -e esp32dev` 編譯正式版。

清潔 UI 測試涵蓋：清潔頁二次確認、一次性 +30／有效 +3 EXP、滿值不加 EXP、四格邊界、中央全白、兩側狀態／底部逐像素保留、所有輸入在 2399ms 仍鎖定、2400ms 的按鍵消耗、清潔度在結束時改變會按即時值重畫、清潔不治病、升級延後、死亡中斷、蛋／睡眠限制、成長延後及毫秒計時溢位。

## 實機操作

1. 建置／燒錄正式 `esp32dev`，進主選單「清潔」。第一次短按仍停在清潔頁；第二次短按回首頁播放動畫。
2. 確認水面只上升，前三格各約 0.4 秒，全白約 1.2 秒；總長約 2.4 秒，直接恢復寵物，沒有退水，也不回清潔頁。
3. 檢查心情／飽食／生病／清潔警示／狀態圖示和底部經驗條沒有被動畫蓋住。清潔警示依結算後的實際值更新，生病十字仍保留。
4. 期間連按與長按、推四方向，不應重複增加清潔／EXP，也不應跳頁；播完後正常導航。
5. 比較前後清潔度：+30、最多 100；依結果保留 0～3 個污漬。清潔滿值再按可播動畫，但不增加 EXP。
6. 有升級時應等全白結束，再接兩秒慶祝，最後在首頁。等待至少 12 秒再正常重啟，確認保存；手機已連線時確認清潔／EXP 通知。

自動 framebuffer 與編譯不代替實機節奏、OLED 亮度、保存與 BLE 驗收。本次不自動燒錄。
