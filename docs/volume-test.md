# 聲音設定：1.7.0 規則與驗收

日期：2026-10-08。依據：韌體 1.7.0 本輪提交來源；完成狀態只在 [主企劃 A5-SOUND](project-plan.md#progress) 維護。2026-10-07 四級音量提案已由兩種聲音模式取代；舊預覽檔只作歷史參考。

## 操作與保存

主選單第三頁「聲音」可供蛋與一般寵物進入；死亡／送別後的結束選單也有入口。進入時焦點在喇叭，左右任一方向都切換到另一種模式，可同方向循環。有聲音試聽 1047 Hz、120ms，靜音不試聽。

喇叭列顯示兩側 `< >`，下方常駐「確定／取消」且無游標。向下進入按鈕列，預選確定並顯示 `>`，隱藏喇叭箭頭；左右只切換按鈕，不影響聲音或試聽。向上回喇叭列，恢復箭頭並隱藏游標；重新往下預選確定，按鈕列重複往下則保留目前選項。喇叭列短按只移到確定，避免直接保存。靜音以喇叭右側 X 表示，正常頁沒有標題、外框或頁碼。[實際 UI framebuffer](sound-focus-ui-preview.png)。

按鈕列短按確定：變更後保存成功直接返回主選單原位置，未變更則不寫入，兩者都有確認回饋；短按取消恢復原設定並返回，有取消回饋。結束選單入口返回結束選單，避免重播死亡流程。任一列長按亦可取消。音效在畫面清理後依最後生效的模式播放，靜音保持無聲。保存失敗時確定按鈕改成「重試」，焦點與取消按鈕保留；短按可重試或取消。成長／死亡中斷撤回未保存變更。

全部音效由 Sound 共用聲音開關：GPIO27、8-bit PWM，有聲音固定 duty=128，靜音為 0。保留既有音高、時長、休止及非阻塞排程；靜音仍完成音序與遊戲等待。固定占空比不是響度百分比，不承諾不同音高一樣響。

獨立 NVS key `volume` 沿用，四位元組為識別值 0x56、版本、模式與模式反碼。新 V2 僅接受 0／1，缺少或無效資料預設有聲音。讀取舊 V1 四級時，0 保留靜音，1／2／3 映射有聲音；開機不寫入，後續實際保存才寫 V2。寫入後讀回核對，失敗不信任快取，可重試修復。正式／測試 namespace 為 `pet-prefs`／`pet-prefs-test`，不改寵物、紀念冊或 BLE 格式。領養不重設；重啟及 Deep Sleep 喚醒在 UI 音效前載入。

## 上板驗收步驟

1. 先斷電核對蜂鳴器限流、驅動與線圈反衝保護；5V、16Ω 電磁式單體不能沿用未知 GPIO 直連作為安全依據。USB 供電不解除 GPIO 負載限制。220Ω 限流與完整驅動的聲音／電氣結果均未量測。
2. 燒錄正式 `esp32dev` 1.7.0，確認原寵物、紀念冊與偏好保留。舊靜音仍靜音，舊非零音量均顯示有聲音，不用清除 NVS。
3. 確認右側 X／聲波、上下焦點及互斥箭頭／游標。喇叭列連續左右均循環；按鈕列連續左右只切換確定／取消、不變更聲音。向上後再向下預選確定；喇叭列短按不保存。短按確定保存並返回原選單位置，短按取消恢復並返回；長按取消捷徑同樣恢復。依最後生效的模式播放確認／取消音。
4. 有聲音時逐層確認紀念冊分類／說明／瀏覽、送別說明／確認／阻擋頁的返回音與確認音；保存靜音，測其他選單的選擇與返回、失敗、遊戲、照顧提醒均無聲；猜拳與記憶音符仍正常完成、等待及結算。再開啟聲音，確認各頁依同一模式播放。
5. 分別保存靜音與有聲音後，正常重啟、完全斷電及 Deep Sleep 喚醒，確認偏好保留；一般睡眠仍依既有規則靜音。Timer 喚醒只測獨立測試版，其偏好與正式版不同。
6. 用獨立測試寵物確認結束選單可設定、領養保留，及成長／死亡打斷時撤回未保存選擇。保存失敗已主機注入，真實 NVS 故障另行安排，不以正常試玩代替。
7. 展示確定使用 USB；以最終電源與接線連續操作超過預計展示時間，確認不重啟或異常發熱。電池續航、低電量與充電測試保留為後續項目。
