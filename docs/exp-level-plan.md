# 經驗與升級規則及驗收

2026-10-02｜韌體 1.4.0｜以包含本文件的 Git 提交為來源；測試於提交前工作目錄完成。進度唯一來源為主企畫 A3-EXP。

## 採用規則

- 新蛋 Lv1／EXP 0；幼鳥及成鳥健康清醒時完成猜拳，整場勝／和／敗分別 +15／+10／+5 EXP，心情沿用既有獎勵。心情滿值不影響 EXP。
- 第三回合揭曉結算一次；中途退出、疾病、死亡、睡眠或成長造成的未完成場次中斷不給獎勵。結算後退出保留成果，重開機不補發或重播。
- 下一級需要 `50 + 25 × (目前等級 − 1)`。EXP 是本級進度，達門檻扣除所需 EXP 並保留餘額；一次獎勵可跨多級。
- Lv20 滿等，EXP 固定 0，下一級門檻 0；顯示 MAX，仍可遊玩及恢復心情。接近滿等時顯示實際接受的 EXP，多餘部分捨棄。
- 清醒時餵食實際提高飽食度 +3 EXP、清潔實際提高清潔度 +3 EXP、成功治癒 +5 EXP；每次有效操作只給一次，補到上限也不加倍。數值已滿的餵食／清潔與健康時治療不給；生病時有效餵食／清潔仍給。蛋、死亡與睡眠期間不執行照顧。Lv20 仍可照顧但不加 EXP。
- 睡眠與時間推進不給 EXP；孵化和成鳥仍依年齡與健康決定。
- 使用既有 NVS V1 level／exp 欄位，格式不變。載入舊值大於門檻時推進等級，舊等級超過 20 則限制為 20／EXP 0。正常舊存檔 Lv1／0 原樣恢復。
- EXP 變動更新 displayRevision，沿用保存排程；結算後等至少 12 秒再重啟驗證。剛結算立刻拔電仍可能失去尚未保存的獎勵。

## 畫面與操作

- 結果頁：勝負 baseline 15、比分 29、心情 45、EXP 60。心情中文佔 y=34..45，與 EXP 字圖之間保留空白。
- 結果頁短按：有升級先播放 2 秒慶祝，否則直接進「再玩／返回」。動畫期間短按及方向消耗，不作用於再玩選擇；長按返回主選單且保留獎勵。
- 慶祝無外框：LEVEL UP! 在 (37,10)；原尺寸 64×44 小鳥在 (32,7)，每秒一次最多上移 2px，共兩次跳動；成鳥可見像素 y=13..50。左星 x=18，在 y=23／39 間閃現；右星 x=109，在 y=37／25 間閃現，晚一格（125ms）開始。兩顆用消失、單點、小十字、大十字的不同節奏呈現，換位前先消失，移動幅度分別為 16／12px。等級在 (25,60)／(78,60)，中間用線段箭頭。音效是非阻塞四音上升音序。
- 多級只播放一次，顯示起始與最終等級；沿用當前幼鳥／成鳥素材，不縮放。疾病、死亡及生命階段轉場仍優先處理。
- 狀態頁四頁：需求／健康與階段／等級與 EXP／年齡。第二頁健康、階段分別位於 baseline 35／55；第三頁等級 baseline 34，EXP 數值 baseline 47、右緣 118，下方進度框縮為 (9,52,110,7)，內部 y=54..56 填充；分隔線 y=18、等級亮點 y=24..34、EXP 亮點 y=40..46、進度框 y=52..58，三段空白各為 5px。滿等顯示 MAX 與滿條；[同字型預覽](exp-status-preview.png)涵蓋幼鳥／成鳥與普通／滿等。
- 主頁及一般睡眠頁底部使用固定 100% 長度的 3px 高外框，範圍 (3,59) 到 (101,61)，與最長的 BABY／Lv20 標籤至少隔 6px。框內 y=60 的 1px 線長度依 `EXP / 下一級門檻` 按比例取整，最大由 x=4 到 x=100；0 EXP 空框、升級後依餘額重新起算、Lv20 滿框。蛋沒有 EXP，保持空框；右側標籤沿用現有文字。實際畫面見 [主頁預覽](exp-home-preview.png)。
- BLE v1 新增可選成組欄位 level、exp、exp_to_next_level；ESP32 為唯一數值來源。新 App 相容舊韌體缺少整組時顯示 --，拒絕不完整或非法資料。規格見 PROTOCOL.md。

## 上板驗收

1. 燒錄正常 esp32dev，健康清醒時完成三回合，對照勝／和／敗的 EXP；心情 100 時仍應增加 EXP。
2. 累積至 50 EXP，確認 Lv2、餘額及 75 門檻；總結果短按看兩秒升級，之後預設返回。動畫期間短按與方向不會選取再玩，長按可返回。
3. 第三回合揭曉後退出，確認獎勵只發一次；第一／第二回合退出不增加。再玩後舊升級動畫不重播。
4. 狀態頁四頁翻看，手機連線確認 level／exp／門檻即時同步；斷線遊玩後重連仍讀取正確資料。
5. 結算後等至少 12 秒再正常重啟，確認等級與 EXP 保存；一般／省電睡眠後數值保留。
6. 回報韌體版本、操作及未測項目，記入主企畫 A3-EXP。生病、死亡、滿等與寫入故障另以可控資料／測試環境驗收。
