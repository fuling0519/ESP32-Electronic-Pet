# 記憶音符：規則與上板驗收

更新日期：2026-10-05。正式韌體版本 1.5.1；進度與驗證結果只在 [主台帳 A5-GAME](project-plan.md#progress) 維護。

## 玩法與入口

主選單「陪玩」→上下選擇「猜拳／記憶音符」→短按進入準備頁→短按開始。準備頁只提示「記住箭頭順序」。長按返回主選單，焦點保留在陪玩。

遊戲面板示範旋律，不限定小鳥或其他物種，也不需要物種專屬動畫。幼鳥／成鳥健康清醒時可玩；蛋提示等待孵化，生病提示請先治療。心情滿值仍可玩；沒有額外體力、入場費、每日限制或冷卻。

每場五回合，序列分別有 2、3、4、5、6 個音符。每回合重新產生獨立隨機方向，允許重複；畫面重繪及 BLE 查詢不重新抽取。聲音與箭頭同步，回答只判斷方向與順序，不判斷踩拍。

- 左／上／右／下對應 Do／Re／Mi／Sol（523／587／659／784 Hz）。
- 示範每個音符亮起並發聲 250ms，再留白 450ms；即使相鄰音符相同也有留白。
- 示範期間的方向及短按丟棄；切入回答時的事件也丟棄，必須先觀察到搖桿回中。
- 回答時一次推動只算一個音符，推完需回中。按住連發或未回中改方向不會成為下一個答案；選單的原本連發行為保留。
- 輸入箭頭亮起並發聲 180ms。一般下一個音符不要求等待亮起結束，只要先回中即可；最後一個正確音符保持在回答畫面，至少滿 180ms 且音效模組確認播放完畢後，才顯示答對畫面、播放答對音效並結算該回合。等待期間方向與短按丟棄，長按仍可退出，不提早發放完成獎勵。
- 每個下一步最多等待 5 秒，從回答階段開始或上一個正確輸入起算。恰好達到期限先判逾時。回中不重設期限。
- 全部正確算答對一回合；答錯／逾時直接結束該回合，顯示正確方向。答對、答錯及逾時畫面至少停留 800ms，再短按繼續；太早的短按丟棄。
- 答錯仍進下一回合，五回合後顯示答對回合數、實際心情／EXP 增量，短按進再玩。再玩預設返回。

更新與音效均使用非阻塞流程；延遲的主迴圈每次只推進一個示範階段，避免跳過玩家尚未看見的音符。

## 獎勵與中斷

- 答對 5 回合：心情 +10，EXP +15。
- 答對 4 回合：心情 +8，EXP +15。
- 答對 2～3 回合：心情 +6，EXP +10。
- 答對 0～1 回合：心情 +3，EXP +5。

第五回合判定完成時結算一次，停留、切頁、再玩及 BLE 重連不重複發放。心情上限 100，滿值顯示 +0 仍取得 EXP；Lv20 的 EXP 接受量為 0。結果頁後若有升級，沿用兩秒慶祝，再進再玩頁。養成、存檔與 BLE 狀態通知沿用現有應用層，不新增存檔欄位或遠端命令。

中途長按退出不發獎勵。遊戲中生病停止未完成場次並顯示治療提示，成長／死亡切入既有轉場；已結算獎勵保留。遊戲沒有睡眠入口，離開後才能選休息；BLE 斷線不停止離線遊戲。重開機不恢復未完成場次，不補發獎勵。保存仍有延後排程，結算後立即拔電不保證保留本次獎勵。

## 128×64 版面

操作畫面採使用者確認的四方向像素草稿；其他頁面沿用外框與 12×12 中文／6×10 ASCII 字型。

- 示範／回答標籤 x=5、baseline 14，右上回合數 x=104、baseline 14，分隔線 y=18。
- 上／左／右／下箭頭中心為 (64,27)／(44,39)／(84,39)／(64,49)，箭頭 9×9，啟用時顯示 17×13 反白底。
- 底部每個進度格 4×4，間距 6px，y=59..62；2～6 格整列置中，實心表示已播放或已正確輸入。回答時不顯示完整答案。
- 準備頁標題 baseline 15；操作說明「記住箭頭順序」baseline 38，開始提示 baseline 58。
- 回合回饋標題 baseline 15、內容 baseline 37／38，繼續提示 baseline 59。
- 結果頁採使用者最後確認的預覽：保留最外圈 1px 畫面框線，表格不畫外框或格線。標題「記憶音符」x=40、baseline 14，實際亮點 y=4..14。下方兩欄三列 baseline 31／46／60；「答對／心情」左欄 x=26，EXP 的 E／X／P 分別 x=27／35／43，字距依 B 方案向內微調；右欄「n/5／+n／+n」以前進寬度右緣 x=101 靠右，與該列標籤共用 baseline。標籤實際亮點 y=21..31／36..46／53..59，標題後空白 6px、後兩段空白 4px／6px，EXP 到底部框線保留 3px 空白。此配置依逐次預覽確認，不再沿用先前無標題／無外框／等間距方案。

## 自動驗證

在專案根目錄執行 `tools/test_rps.ps1`，涵蓋猜拳、記憶音符領域及實際 UI、寵物核心與心情回歸。使用現有 native gcc／g++ 及正式環境的 U8g2。畫面重新產生使用 `tools/render_memory_notes_preview.py`（需要 Pillow）。

記憶音符領域測試覆蓋 0～5 分及四個方向、五回合長度與抽樣次數、連續相同方向、示範留白、回中與連發、逾時邊界與重設、millis 溢位、延遲更新、取消與再玩。實際 UI 測試覆蓋同一結算路徑、各獎勵級距、心情上限、EXP／升級餘額、選單導航及蛋／生病／成長／死亡中斷；像素繪圖檢查邊界與所需中文字圖。

## 上板驗收

1. 燒錄正式 `esp32dev`，手機裝置資訊應顯示 1.5.1。使用原存檔，不需清除 NVS。
2. 陪玩能上下選猜拳／記憶音符，短按進入、長按返回；猜拳心情仍為 10／6／3、EXP 15／10／5。
3. 示範依序亮箭頭與發聲，相同方向的相鄰音符能清楚辨認；四方向音高有差異。
4. 完成最後一個正確音符時，先聽完該音並看到箭頭亮起，再進答對畫面／答對音效，兩者不搶音；等待時短按不跳過回饋。示範時推住搖桿，回答開始後仍推住不能算答案；回中後推一次只算一次，按住不連答，連續相同方向必須回中再推。
5. 答錯與逾時顯示正確方向，短按仍可進下一回合；五回合依序有 2～6 個音符，回合數與進度一致。
6. 完成後對照各分數的心情及 EXP；接近心情滿值顯示實際增量，滿值仍拿 EXP，升級在結果後播放，停留不重複領取。
7. 中途長按無獎勵，再玩清除前場回合／分數；遊戲時間仍推進養成，生病／成長／死亡時中止。
8. 手機 BLE 連線時遊玩，結果數值通知同步；斷線仍可玩。結算後等至少 12 秒再正常重啟，確認保存；回歸一般及省電睡眠。

本文件的自動測試與預覽不代表蜂鳴器聽感、搖桿實物、BLE 無線同步或存檔實機驗收通過。實機結果記回唯一進度台帳。
